# 🏋️ FitLog

## Project Description
FitLog is a modern fitness workout tracker that helps users discover exercises,
view detailed workout instructions, build daily workout plans, and track
important training metrics.

## Technologies Used

- **Next.js** — React framework for building the application
- **TypeScript** — Type-safe development
- **Next.js App Router** — Page navigation and dynamic routing
- **Tailwind CSS** — Responsive UI styling and layouts
- **DaisyUI** — Reusable UI components
- **React Icons** — Icons throughout the application
- **React Toastify** — User-friendly toast notifications

## Key Features

1. 📚 Exercise Library — Browse a collection of fitness and strength exercises.
2. 🔎 Exercise Details — View equipment, sets, reps, duration, calories, and instructions.
3. 📅 Personal Workout Plan — Create and manage a daily training routine.
4. 📊 Workout Tracking — Monitor workout metrics and exercise progress.
5. 🌙 Modern Dashboard — Use a clean, responsive dark-themed fitness interface.
